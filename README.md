- Vite

## Development

Node.js가 설치된 VS Code에서 이 폴더를 연 뒤 다음 명령을 실행합니다.

```bash
npm ci
npm run dev
```

Windows PowerShell 실행 정책으로 `npm` 실행이 차단되면 `npm.cmd run dev`를
사용할 수 있습니다. 이 워크스페이스는 VS Code의 기본 터미널을 Command Prompt로
설정해 해당 문제를 피합니다.

VS Code에서는 다음 방법도 사용할 수 있습니다.

- `F5`: `Mimora: npm run dev` 디버그 구성 실행
- `Ctrl+Shift+B`: 타입 검사 후 Electron과 React 앱 빌드
- `Terminal > Run Task`: 설치, 개발 서버, 타입 검사, 빌드 작업 실행
